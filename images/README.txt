Thêm ảnh của bạn vào đây (tên file phải đúng, thiếu ảnh thì ô ảnh để trống màu xám):
images/hero.jpg          -> ảnh nền lớn ở đầu trang chủ
images/food/1.jpg ... 10.jpg -> ảnh món ăn (số = id trong js/data.js)
images/cat/1.jpg ... 5.jpg   -> ảnh danh mục (thứ tự: Món nước, Cơm, Ăn vặt, Pizza & Burger, Đồ uống)
Nhớ ghi nguồn ảnh (nếu lấy từ Unsplash, Pexels...) vào báo cáo.
