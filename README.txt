THƯ MỤC ẢNH (images/) – tất cả khung ảnh trên web đang để trống (nền xám). Bỏ file vào đúng tên là tự hiện.

images/food/1.jpg ... 17.jpg      Ảnh món ăn (số = id trong data.js). Hiện ở thẻ món, giỏ hàng, đơn hàng, menu cửa hàng
images/store/1.jpg ... 14.jpg     Ảnh cửa hàng (vuông)
images/cat/1.jpg ... 7.jpg        Ảnh danh mục (1 Món nước, 2 Cơm, 3 Ăn vặt, 4 Pizza & Burger, 5 Đồ uống, 6 Tráng miệng, 7 Món chay)
images/quick/1.png ... 7.png      Ô vuông trên cùng trang chủ (Món nước, Cơm, Đồ uống, Xe máy, Ô tô 4 chỗ, Yêu thích, Ưu đãi)
images/vehicle/bike.png, car4.png, car7.png   Ảnh loại xe ở trang Đặt xe
images/empty-cart.png             Hình minh họa giỏ hàng trống
images/video-poster.jpg           Ảnh bìa video (tùy chọn)
images/mb-qr.png                  Ảnh QR MB Bank tự chụp (chỉ dùng khi chưa điền số tài khoản trong config.js)

Dùng tên/đuôi khác (png, webp...)? Thêm thuộc tính img trong data.js, ví dụ: { id: 1, name: "Phở bò", ..., img: "images/food/pho-bo.png" }

VIDEO: đặt file vào video/intro.mp4 hoặc đổi INTRO_VIDEO trong js/config.js (hỗ trợ cả link YouTube).
